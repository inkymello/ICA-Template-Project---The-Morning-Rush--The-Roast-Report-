Chart 3: How much – Daily revenue vs units sold scatter plot with regression

Purpose

Explore how tightly daily revenue tracks units sold.

Functionality

  • One point per store-day (543); size shows transactions
  • Drag a box to zoom; reset button restores the view

Insights

  • y = 3.20x + 23.59: about $3.20 per extra unit
  • R² = 0.939, correlation +0.969
  • A few outlier days earn more than their units predict

Design reflection

Axes start at zero. One overall trendline (not one per store) is a recorded limitation.
